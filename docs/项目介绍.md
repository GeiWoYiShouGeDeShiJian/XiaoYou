# 小柚记账 · 项目介绍

> 一款单机、注重隐私的 Android 个人记账应用。
> 本文档用于快速了解产品定位、功能全貌与技术亮点。技术细节见《最终设计文档》。

---

## 一、产品简介

**小柚记账**是一款完全离线运行的个人记账应用，对标「小星记账」「钱迹」等主流工具。所有数据保存在本地加密数据库中，无网络权限、无服务器、无广告，隐私安全。

核心 slogan：**数据不出手机，账目清清楚楚。**

| 项 | 说明 |
|---|---|
| 应用名 | 小柚记账 |
| 运行平台 | Android 7.0+（minSdk 24） |
| 数据存储 | 本地 SQLCipher 加密数据库（17 张表） |
| 联网 | 无 INTERNET 权限，纯离线 |

## 二、功能亮点

### 1. 完整记账体系
- **四类交易**：支出、收入、转账、借贷，金额精度到分（Long 存储，无浮点误差）。
- **扩展属性**：商家、标签、多选成员、付款状态（已付/未付）、报销标记、退款明细、优惠金额、转账手续费、还款日，最多 4 张图片附件。
- **快捷记账模板**：常用账单一键套用，支持快速保存。

### 2. 多账本多账户
- 多账本自由切换，账本可自定义封面、图标、配色、本位币、隐藏。
- 账户分组管理、共享账户（跨账本共用）、计入净资产开关、零余额自动隐藏。

### 3. 智能记账
- **自动记账**（核心亮点）：无障碍 + 通知监听双通道，识别微信/支付宝支付页与账单详情、主流支付 App 通知，悬浮窗一键确认入账；支持弹窗/通知/静默三种模式，识别日志可审计，重复交易自动拦截。
- **语音记账**：语音识别直接生成账目。
- **文字解析**：一句话（如"午餐 35 元"）自动提取金额并推荐分类。
- **关键词记忆**：记住备注关键词与分类的对应关系，越用越准。

### 4. 官方账单导入
- 微信/支付宝官方导出的 CSV 账单自动识别、解析，按表头动态匹配列（兼容编码与列顺序差异），中性账（提现/充值/退款）自动跳过，重复导入自动去重。

### 5. 管理能力
- **预算**：月/年预算，结余滚动累计，超支 50%/80%/100% 分级提醒。
- **周期记账**：房租、会员等固定支出自动入账，每日补跑。
- **报销管理**：待报销→已报销全流程，与支出/收入双向联动。
- **应收应付**：借出/借入按成员分组，待收/待付一目了然，支持还款日。
- **回收站**：误删可恢复，超 7 天自动清理。
- **高级搜索**：金额区间、备注、类型、分类、账户、标签（OR/AND）、日期组合筛选，分页加载。

### 6. 自定义首页
- 首页模块（结余、收支统计、分类占比、预算、快捷入口、最近交易）**显隐与排序自由配置**。
- 结余/收入/支出 9 档数据项任选 3 个展示；下拉手势可设为刷新/快速记账/搜索。

### 7. 统计可视化
- 收支趋势、分类占比环形图、消费排行、收支日历。
- 首页金额滚动动画，账本级配色。

### 8. 安全与便捷
- **数据库加密**：SQLCipher 透明加密，根密钥由系统 Keystore 保护。
- **应用锁**：生物识别解锁。
- **加密备份**：AES-GCM + 密码，跨设备迁移。
- **桌面 Widget**：快捷记账（2×1）、收支概览（4×2）。
- **URL Scheme**：`jizhang://record?...` 支持第三方快捷记账。
- **深色模式**：三色系主题 + 跟随系统 + 动态取色。

## 四、技术亮点

| 方向 | 实现 |
|---|---|
| 架构 | 单 Activity + Jetpack Compose + MVVM + Hilt，UI 无状态、DAO Flow 响应式刷新 |
| 精度 | 金额全链路 Long(分)，杜绝浮点误差 |
| 加密 | SQLCipher + Keystore 派生根密钥 |
| 自动记账 | 双通道采集 + 规则引擎（规则与代码分离）+ 三层防重 + 悬浮窗 Compose 挂载 |
| 去重 | 交易单号/指纹双重去重（MD5） |
| 后台 | WorkManager：周期补跑（00:30）、回收站清理（03:00）、预算提醒 |
| 主题 | Material 3 全套 Token，设计令牌集中管理，杜绝硬编码 |
| 统计 | Vico 图表 + Canvas 自定义环形图 |
| 迁移 | Room schema 版本化导出，17 表 22 版本渐进迁移 |

技术栈：Kotlin 2.4 · Compose BOM 2026.06 · Hilt · Room 2.7 · SQLCipher · WorkManager · Glance · Vico。

## 五、项目规模与状态

- **单模块** `:app`，约 170 个 Kotlin 源文件。
- **数据库**：17 张表，版本 22，迁移链完整。
- **功能完成度**：核心记账、账本、统计、预算、周期、回收站、搜索、Widget、语音/文字、CSV 导入、自动记账、自定义首页、报销、应收应付、加密备份、应用锁均已完成。
- **待实现**：多币种汇率换算、记账提醒、分期付款管理（详见《最终设计文档》第 10 节）。

## 六、适用场景

- 个人 / 家庭记账，注重隐私、拒绝云同步的用户。
- 微信/支付宝高频消费，想免手工记账的用户（自动记账）。
- 需要报销管理、借贷往来、预算控制的上班族与经营者。
- 记账数据敏感、需要完全离线与加密存储的用户。
