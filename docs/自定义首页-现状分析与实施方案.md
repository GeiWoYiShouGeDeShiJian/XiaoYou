# 自定义首页 · 现状分析与实施方案

> 目标：复刻小星记账「自定义首页」，实现首页数据概览卡片可配置、模块显隐/排序可配置、全局设置可配置。

> 项目：小柚记账（JiZhangRuanJian）
> 日期：2026-08-27

## 一、现状盘点（已有能力）

### 1.1 首页结构（`ui/home/HomeScreen.kt`）

当前首页为固定结构（LazyColumn），自上而下：

1. 顶部栏：菜单 + 账本切换（下拉）+ 日期 + 搜索
2. 本月结余卡片（`BALANCE`，渐变背景，结余/收入/支出/环比）
3. 今日 / 本周 / 本月支出三个统计卡（`STATS`）
4. 支出分类占比（`CATEGORY`，DonutChart 环形图）
5. 预算（`BUDGET`，进度条 + 剩余日均）
6. 快捷入口（`QUICK_ENTRANCE`）
7. 最近交易（`RECENT`，按日期分组 + 左滑编辑/右滑删除）

各模块显隐由 `HomeUiStore.hidden`（`Set<HomeSection>`）控制，设置页有对应开关。

### 1.2 数据能力（`data/repository/TransactionRepository.kt`）

已有：`homeSummary`（本月收支 + 环比 + 分类占比）、`todayExpense`、`weekExpense`、`statistics`（区间统计）、`dailyExpenses`。
`TransactionDao.sumByType(ledgerId, type, from, to)` 支持任意类型 + 区间，可直接复用扩展。

### 1.3 配置存储（`data/HomeUiStore.kt`）

仅支持 `hidden`（key = `home_hidden_sections`），无 `HomeConfig` 概念。

### 1.4 导航（`ui/navigation/AppNavGraph.kt`）

状态驱动导航（`currentTab` / `drawerPage` / `showBudget`），非 NavHost。新增页面需扩展状态分支。

## 二、差距分析（要解决的问题）

### P1 数据层：HomeConfig 缺失
- **现状**：HomeUiStore 只有 hidden。
- **目标**：HomeConfig 全量配置（数据一/二/三、统计卡片、封面、模块显隐/排序、全局设置）。
- **解决**：
  - 新增 `HomeConfig` 数据类 + 枚举（`HomeDataOption` / `CoverTextColor` / `PullDownAction`）。
  - HomeUiStore 扩展：`config: StateFlow<HomeConfig>` + `updateConfig(...)`，JSON 存 `app_setting`（key = `home_config`）。
  - 需确定 JSON 序列化方案（见 Q1）。

### P2 统计能力缺口
- **现状**：只有今日/本周/本月支出。
- **目标**：数据选择器需 9 个值——本月结余/收入/支出、本周支出/收入、今日支出/收入、年度结余/支出、无。
- **解决**：TransactionRepository 新增 `todayIncome`、`weekIncome`、`yearIncome`、`yearExpense`（复用 `sumByType`），`yearBalance = yearIncome - yearExpense`。

### P3 首页动态渲染
- **现状**：模块顺序硬编码，显隐靠 hidden。
- **目标**：按 `moduleOrder` 顺序渲染 + `showXxx` 开关 + 数据概览按 `dataOne/Two/Three` 与 `statCardA/B/C` 显示。
- **解决**：重构 HomeScreen，数据概览（结余 + 统计卡）合并为 `DataOverviewCard` 整块可点击，其余模块按配置渲染。

### P4 红框点击跳转
- **现状**：数据概览无点击事件。
- **目标**：点击数据概览 → 跳自定义首页；`clickCoverToSwitchLedger` 开启时改为切换账本。
- **解决**：`DataOverviewCard` 加 `clickable`，按配置分支跳转 / 切换账本。

### P5 最近交易数量
- **现状**：`observeRecent` 固定 5 条。
- **目标**：按 `recentTransactionCount`（3/4/5/10 条）。
- **解决**：HomeViewModel 读取配置，`observeRecent(ledgerId, count)`。

### P6 下拉操作
- **现状**：无下拉手势。
- **目标**：下拉 = 刷新 / 快速记账 / 搜索 / 无。
- **解决**：Material3 `PullToRefreshBox` 包裹 LazyColumn，按配置分发。

### P7 导航新增页面
- **现状**：状态驱动导航。
- **目标**：新增「自定义首页」页面。
- **解决**：AppNavGraph 新增状态分支（如 `customizeHome`），首页红框跳转；设置页新增入口。

### P8 自定义首页页面（全新）
- **目标**：预览卡片 + 数据配置 + 全局设置 + 卡片顺序（拖拽）。
- **解决**：新增 `ui/home/CustomizeHomeScreen.kt` + `CustomizeHomeViewModel.kt`。

### P9 拖拽排序
- **现状**：无拖拽能力。
- **解决**：需确定拖拽方案（见 Q2）。

### P10 账本封面
- **现状**：无封面概念。
- **目标**：背景图 / 纯色 / 自定义图片 + 封面文字浅/深色。
- **解决**：封面选择器 + 图片存储（复用 `ImageSaver`）+ 预览渲染。**已确认：封面先做全局一份，自定义图片功能未来再加，本期仅支持纯色 / 默认背景。**

### P11 设置页整合
- **现状**：设置页有「自定义首页」显隐开关区块。
- **目标**：与新的 HomeConfig 功能重叠，需整合。**已确认：首页数据概览（结余 + 统计卡片）整块可点击进入自定义首页；设置页保留「自定义首页」入口按钮，移除原显隐开关（显隐迁移到自定义首页页面）。**

### P12 旧配置迁移
- **现状**：`home_hidden_sections` 已有存量数据。
- **目标**：迁移到 HomeConfig。
- **解决**：首次读取 `home_config` 不存在时，由 `home_hidden_sections` 生成初始值（hidden 含某 section → 对应 `showXxx = false`）。

## 三、实施方案（分步骤）

### Step 1 数据层
1. 新增 `data/model/HomeConfig.kt`（HomeConfig + 3 枚举）。
2. 扩展 `HomeUiStore`：`config` StateFlow + `updateConfig` + 旧配置迁移（**Gson 序列化**，key = `home_config`）。
3. `TransactionRepository` 新增 `todayIncome` / `weekIncome` / `yearIncome` / `yearExpense`。
4. `libs.versions.toml` 新增 `gson` 与 `reorderable` 依赖。

### Step 2 首页改造
1. HomeScreen 重构：数据概览（结余 + 统计卡）合并为 `DataOverviewCard`，**整块可点击**进入自定义首页（`clickCoverToSwitchLedger` 开启时改为切换账本）。
2. 按 `moduleOrder` + `showXxx` 动态渲染。
3. 最近交易数量、下拉操作接入。

### Step 3 自定义首页页面
1. 新增 `ui/home/CustomizeHomeScreen.kt` + `CustomizeHomeViewModel.kt`。
2. 预览卡片、数据配置、全局设置、卡片顺序（**reorderable 拖拽**）。
3. 封面本期仅纯色 / 默认背景选择。

### Step 4 导航接入
1. AppNavGraph 新增「自定义首页」状态分支。
2. 首页红框跳转 + 设置页入口按钮（移除原显隐开关）。

### Step 5 联调
1. 配置修改 → 即时保存 → 返回首页生效。
2. 旧配置迁移验证。
